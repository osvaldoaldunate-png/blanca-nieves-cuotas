# Control de Cuotas - Escuela de Lenguaje Blanca Nieves

## Publicar en Vercel
1. Descomprime este ZIP.
2. En Vercel crea un proyecto nuevo.
3. Sube/importa esta carpeta (o súbela a GitHub y conecta el repositorio).
4. No requiere framework ni comando de build: es un sitio estático.
5. El archivo principal es `index.html`.

## Importante
Esta versión guarda la información en `localStorage` del navegador.
Eso significa que los datos quedan en el dispositivo/navegador donde se registran.
Para uso institucional compartido entre varios dispositivos, conviene una segunda versión con base de datos y acceso con contraseña.
